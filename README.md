## 📖 Guide Rapide

### Écouter une Radio
1. **Cherche** avec la barre de recherche
   - Tape "NRJ", "Skyrock", "Jazz"... → résultats instantanés
2. **Clique** sur le bouton ▶ de la radio
3. **Ajuste** le volume avec le slider

### Ajouter aux Favoris
1. Cherche ta radio
2. Clique sur le cœur ♡ (devient ❤️)
3. Accède instantanément dans l'onglet "⭐ Favoris"

### Changer de Thème
1. Ouvre le dropdown "🎨 Thème:" en haut
2. Sélectionne ton thème préféré
3. C'est appliqué immédiatement (et sauvegardé!)

### Filtrer par Genre
1. Clique sur un genre (Rock, Électro, Classical...)
2. Vois seulement les radios de ce genre
3. Recherche dans ce genre avec la barre

## 🐛 Dépannage Rapide

### "Aucune radio ne se charge"
→ Vérifiez votre connexion Internet  
→ L'app utilise automatiquement les radios locales si l'API est down  
→ Redémarrez l'application

### "Le son ne vient pas"
→ Vérifiez le slider de volume (pas à 0%)  
→ Vérifiez les volumes système Windows  
→ Réinstaller les drivers audio  
→ Essayez une autre radio (certaines streams peuvent être offline)

### "L'app crash au démarrage"
→ Désinstallez puis réinstallez  
→ Supprimez le dossier `%AppData%\Lecteur Radio Royal\`  
→ Vérifiez que vous avez les droits admin

### "Je veux réinitialiser mes paramètres"
→ Fermez l'app  
→ Supprimez: `C:\Users\[VotreNom]\AppData\Roaming\Lecteur Radio Royal\`  
→ Redémarrez l'app
