# 🎵 Lecteur Radio Royal

App desktop Windows pour écouter des radios françaises en ligne avec style!

## ✨ Fonctionnalités

- 🎵 Écoute 1000+ radios francophones
- 🎨 des dizaines de skins (gratuit + premium)
- 🔐 Système de license premium
- 🚀 Mise à jour automatique

## 📥 Installation

Télécharger la dernière version: [Releases](https://github.com/Lesappsroyales/lecteur-radio-royal/releases)

## 🔧 Technologie

- Python 3.x
- Tkinter / CustomTkinter (UI)
- VLC (streaming audio)
- Requests (mise à jour)
